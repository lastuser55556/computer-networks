# Краткая выжимка: TCP и UDP

1. TCP и UDP — протоколы транспортного уровня, которые передают данные между приложениями по номерам портов.
2. Порт вместе с IP-адресом помогает определить нужное приложение на устройстве, а комбинация адресов и портов клиента и сервера образует сокет TCP-соединения.
3. TCP — протокол с установлением соединения: перед передачей стороны согласуют параметры сеанса.
4. TCP обеспечивает надёжную доставку, нумерует байты и подтверждает получение сегментов с помощью ACK.
5. При потере сегмента TCP повторно отправляет данные, а при нарушении порядка собирает поток в правильной последовательности.
6. Скользящее окно позволяет TCP передавать несколько сегментов до получения подтверждения и управлять потоком данных.
7. TCP также регулирует скорость передачи при перегрузке сети, изменяя размер окна.
8. UDP — протокол без установления соединения, который передаёт независимые датаграммы с минимальным заголовком.
9. UDP не гарантирует доставку, порядок и отсутствие дубликатов, поэтому приложение при необходимости должно обрабатывать эти случаи самостоятельно.
10. TCP обычно выбирают для HTTP, FTP и SMTP, а UDP удобен там, где важнее скорость и малая задержка, например для потоковой передачи, DNS и голосовой связи.
