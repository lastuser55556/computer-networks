# IPv4 адресация и разделение на подсети

## Цель работы

Разработать схему IPv4-адресации для сети из пяти зданий в Cisco Packet Tracer.

## Исходные данные

Для работы использована сеть:

```text
192.168.0.0/24
```

Для каждого здания требуется от 15 до 25 устройств. Для такой задачи подходит маска `/27`, потому что она дает 30 доступных адресов для устройств.

```text
/27 = 255.255.255.224
```

## Пример настройки ПК

Для `PC0` использованы следующие параметры:

```text
IPv4 Address: 192.168.0.2
Subnet Mask: 255.255.255.224
Default Gateway: 192.168.0.1
```

## Ответ на вопрос

Нужно найти длину префикса для 20 подсетей и 10 узлов.

Для 10 узлов нужна подсеть `/28`, потому что она дает 14 доступных адресов:

```text
2^4 - 2 = 14
```

Но из сети `/24` при делении на `/28` получится только 16 подсетей:

```text
2^4 = 16
```

Для 20 подсетей из сети `/24` нужна маска `/29`, но она дает только 6 доступных адресов:

```text
2^3 - 2 = 6
```

Вывод: из одной сети `/24` нельзя одновременно получить 20 подсетей и по 10 узлов в каждой. Для этого нужна сеть большего размера, например `/23`.
