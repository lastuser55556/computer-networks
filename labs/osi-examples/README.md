# Домашнее задание: модель OSI

## Задание

Нужно взять объект, систему или ошибку — всего 5 примеров — и соотнести каждый пример с одним из уровней модели OSI. В качестве результата нужно отправить ссылку на этот репозиторий.

## Примеры

### 1. Повреждён сетевой кабель

- **Уровень OSI:** физический.
- **Объяснение:** физический уровень отвечает за передачу битов по среде связи: кабелю, оптоволокну или радиоканалу. Если кабель повреждён, сигнал и биты не могут нормально передаваться.

### 2. Коммутатор пересылает кадр по MAC-адресу

- **Уровень OSI:** канальный.
- **Объяснение:** на канальном уровне данные передаются в виде кадров. Здесь используются MAC-адреса, а коммутаторы выбирают, в какой порт передать кадр.

### 3. Маршрутизатор выбирает путь до другой сети

- **Уровень OSI:** сетевой.
- **Объяснение:** сетевой уровень работает с пакетами и IP-адресами. Маршрутизатор анализирует IP-адрес назначения и выбирает маршрут, по которому отправить пакет.

### 4. Браузер получает страницу по TCP

- **Уровень OSI:** транспортный.
- **Объяснение:** транспортный уровень обеспечивает передачу данных между процессами. TCP устанавливает соединение, контролирует доставку и при необходимости запрашивает повторную отправку потерянных сегментов.

### 5. Открытие сайта по HTTP

- **Уровень OSI:** прикладной.
- **Объяснение:** прикладной уровень связан с пользовательскими сетевыми приложениями и протоколами. HTTP позволяет браузеру запросить страницу у веб-сервера и получить ответ.

## Краткий вывод

Каждый уровень OSI решает свою задачу: от передачи битов по среде связи до работы пользовательских приложений. Вместе они позволяют устройствам обмениваться данными по сети.
