# Сеть в Cisco Packet Tracer

## Задание

Построить сеть в Cisco Packet Tracer с 8 компьютерами, 2 коммутаторами и 1 хабом. Проверить связь между компьютерами через `ping` и показать работу симулятора.

## Схема сети

В работе использованы:

- 8 компьютеров;
- 2 коммутатора;
- 1 хаб.

Структура сети:

```text
PC0, PC1, PC2, PC3 -> Switch0 -> Hub0 -> Switch1 -> PC4, PC5, PC6, PC7
```

## IP-адреса

Компьютеры настроены в одной локальной сети:

| Устройство | IP-адрес | Маска |
| --- | --- | --- |
| PC0 | 192.168.1.1 | 255.255.255.0 |
| PC1 | 192.168.1.2 | 255.255.255.0 |
| PC2 | 192.168.1.3 | 255.255.255.0 |
| PC3 | 192.168.1.4 | 255.255.255.0 |
| PC4 | 192.168.1.5 | 255.255.255.0 |
| PC5 | 192.168.1.6 | 255.255.255.0 |
| PC6 | 192.168.1.7 | 255.255.255.0 |
| PC7 | 192.168.1.8 | 255.255.255.0 |

## Проверка

Связь проверена командой:

```text
ping 192.168.1.8
```

Пакеты были отправлены с `PC0` на `PC7`. Потерь нет.
