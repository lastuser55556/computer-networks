# Скриншоты

В эту папку добавляются скриншоты выполнения задания в Cisco Packet Tracer.

Рекомендуемые имена файлов:

- `01-topology.png` — общая топология двух заданий;
- `02-task1-ip.png` — пример настройки IPv4 для задания 1;
- `03-task1-ping.png` — проверка ping для задания 1;
- `04-task2-ip.png` — пример настройки IPv4 для задания 2;
- `05-task2-ping.png` — проверка ping для задания 2.
